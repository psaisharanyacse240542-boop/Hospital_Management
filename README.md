# 🏥 Online Hospital Bed Booking System

A web-based application that allows users to **check hospital bed availability and book beds online** quickly and conveniently.

### ✨ Features

* User registration and login
* Check available hospital beds
* Online bed booking
* Patient details management
* Booking confirmation
* Hospital and bed management

### 🛠️ Technologies

**HTML | CSS | JavaScript | Node.js | Express.js | MySQL**

### 🎯 Objective

To simplify hospital bed booking, reduce waiting time, and improve efficient bed management.

### 🚀 Future Scope

Mobile application, online payments, SMS/email notifications, and AI-based bed availability prediction.

**Developed as an academic project.**
